Where the clean session runs

The clean session is this same page opened with no cookies, no login and no history. The price it gets is what you are compared with.

This build has no server. Every comparison happens on this device and nothing is sent anywhere, on any website. The settings below exist only in builds made with the optional server switched on.

Companies the server may be contacted about

In the two server modes, the extension contacts the server only for these companies. Every other website is compared on this device or not at all. This list is fixed in the code and can be checked in the repository.
